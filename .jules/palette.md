## 2026-04-02 - Added `aria-hidden` to Material Symbols Ligatures
**Learning:** Google Material Symbols are implemented as ligatures within standard text tags (`<span>`). Without `aria-hidden="true"`, screen readers will read the literal string of the icon (e.g. "verified_user") out loud, confusing users and adding cognitive load. Furthermore, UI elements like input `<select>` must be explicitly associated with their hints/errors using `aria-describedby`, and the `disabled` state must also reflect as `aria-disabled="true"` for maximum AT compatibility.
**Action:** Always add `aria-hidden="true"` to Google Material Symbols / icon ligatures. Ensure interactive states toggle ARIA properties (like `aria-disabled`) along with the native DOM property, and relate inputs to hints using `aria-describedby`.
