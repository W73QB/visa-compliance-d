## 2026-03-27 - Enhance Label Associations and Descriptions for Accessibility
**Learning:** Found that `<select>` elements and labels were not explicitly linked in `ui/index.html`. Material icons also lacked `aria-hidden` tags. Using a python script modifying files in binary mode prevents CRLF issue while programatically applying attributes like `aria-hidden` over all occurrences ensuring elements are properly linked with hints via `aria-describedby`.
**Action:** Always ensure custom styled `<select>` elements explicitly define an `aria-describedby` when a hint text follows, and explicit `for` attributes on `<label>`s to avoid loss of screen-reader context in multi-layered components. Decorative text-based icon fonts must explicitly contain `aria-hidden="true"`. Make sure to avoid committing any temporary scripts or downloaded binaries after testing!
