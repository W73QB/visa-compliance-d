## 2024-06-25 - Form Labels and Hints in Flex-Col Layouts
**Learning:** In flex-col layouts where inputs are visually separated from their labels or accompanied by helper text, screen readers struggle to associate them correctly without explicit attributes. The native `for` attribute on `<label>` is critical for linking the label text to the input ID, especially when clicking the label doesn't naturally focus the input due to the layout. Additionally, helper text elements (like `<p id="visaHint">`) need to be programmatically associated with their corresponding inputs (like `<select>`) using `aria-describedby` so the hint is announced to screen reader users when the input receives focus.
**Action:** Always ensure that form labels have a `for` attribute pointing to the input's `id`, and use `aria-describedby` on input elements to link them to any supplementary hint or error text, regardless of visual proximity.
