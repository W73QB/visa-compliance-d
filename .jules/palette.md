## 2024-03-05 - Add comprehensive accessibility improvements to UI
**Learning:** Found several missing accessibility attributes across the UI: icons acting as buttons lacked `aria-label`, forms lacked explicit `for` bindings associating labels to inputs (`visaSelect`, `productSelect`), the evidence modal lacked `role="dialog"`, `aria-modal="true"`, and `Escape` key close support, and all Google Material Symbol icons lacked `aria-hidden="true"`, causing screen readers to read the icon name out loud.
**Action:** Applied patches to `ui/index.html` to add explicit `for` attributes to labels, added `aria-describedby` to inputs pointing to hints, added `aria-hidden="true"` to all material symbol spans, added `aria-label` to the support button, and added full accessible modal markup + escape key support.
