## 2025-04-17 - Accessible Form Labels and Disabled Buttons
**Learning:** Native `<select>` form inputs combined with Tailwind flex layouts often visually disconnect the label from the input. Screen readers require an explicit `for` attribute on `<label>` elements matching the input's `id`. For inputs with supplementary descriptive text like hints, `aria-describedby` must link the input to the hint container. Disabled buttons must use `aria-disabled="true"` alongside the native `disabled` attribute so screen readers properly announce their inactive state.
**Action:** Ensure all form inputs have a properly linked `<label>` with a `for` attribute, use `aria-describedby` for helper text, and keep `aria-disabled` synchronized with the native `disabled` property in JavaScript.
