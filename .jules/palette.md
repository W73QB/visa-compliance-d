## 2024-05-20 - Decoupled Labels and Material Symbol Screen Reader Clutter
**Learning:** In this application's components, `<label>` elements are frequently decoupled from their inputs visually due to `flex-col` wrappers (e.g., custom select menus with Material Symbol icons inside relative wrappers). This makes explicit `for` and `aria-describedby` associations critical for accessibility. In addition, decorative Material Symbol ligatures rendered as `<span class="material-symbols-outlined">icon_name</span>` are read out by screen readers as their raw text name (e.g., "gavel") if `aria-hidden="true"` is not explicitly applied, leading to severe screen reader clutter within form controls.
**Action:** Always ensure that explicit `for` attributes on labels map to input IDs, ensure helper text uses `aria-describedby` on the input, and ensure any text-based icon ligatures inside interactive form elements or wrappers have `aria-hidden="true"`.
