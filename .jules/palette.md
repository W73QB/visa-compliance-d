## 2026-04-16 - Add explicit form labels, ARIA attributes, and disabled states
**Learning:** In this application's custom select inputs (`#visaSelect`, `#productSelect`), the visual labels were separated from the form elements using flex/grid layouts without native association. Additionally, Google Material Symbols (ligatures) are rendered as literal text to screen readers if `aria-hidden` is omitted.
**Action:** Always use the explicit `for` attribute on `<label>` elements linking to input IDs, ensure instructional hints use `aria-describedby` to associate with the inputs, and wrap all purely decorative `material-symbols-outlined` span tags with `aria-hidden="true"`. Also, dynamically toggling a button's disabled state via JS requires synchronizing the `aria-disabled` property for screen readers to correctly announce the state.
