## 2026-03-31 - Explicit Form Associations and Decorative Icons
**Learning:** The flex-col layout separates labels from inputs visually, so screen readers fail to associate them without explicit `for` attributes. Furthermore, dynamic native `<select>` elements require `aria-describedby` to link their helper text (`#visaHint`, `#productHint`), and Material Symbols implemented as ligatures must have `aria-hidden="true"` to prevent them from being read aloud as their literal text (e.g., "gavel", "health and safety").
**Action:** Always ensure that form labels use explicit `for` attributes connecting to input `id`s, attach helper text via `aria-describedby` on the inputs themselves, and strictly use `aria-hidden="true"` on decorative ligature-based icons inside interactive components.
