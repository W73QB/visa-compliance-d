## 2024-06-17 - Added Form and Menu Accessibility Attributes
**Learning:** Form `<label>` tags with custom class-based styling were lacking `for` attributes connecting them to their `<select>` elements, and `<select>` elements missed `aria-describedby` linking them to their hint paragraphs, which breaks the experience for screen reader users. Additionally, the mobile menu button was missing `aria-expanded` and `aria-controls` attributes, preventing users from understanding its state and controlled element.
**Action:** Ensure all form labels include a `for` attribute referencing the exact ID of their associated input element. Use `aria-describedby` to link input hints or error messages to the inputs. Include `aria-expanded` and `aria-controls` for any custom dropdown or toggle menu components, and update the state programmatically in JavaScript.
