## 2025-02-28 - Icon and Input Accessibility Fixes
**Learning:** In this UI, Google Material Symbols are implemented as ligatures within `<span>` tags, which requires `aria-hidden="true"` to prevent screen readers from reading out the literal icon names (like "verified_user"). Additionally, labels for inputs located inside flex layouts needed explicit `for` attributes linking them to their target input `id` to ensure proper association, and toggle buttons (like the mobile menu) require dynamic `aria-expanded` attributes updated via JavaScript to convey their correct state.
**Action:** Always add `aria-hidden="true"` to decorative icons (especially text-ligature ones), verify `for` to `id` mappings for all inputs particularly in flex/grid layouts, and ensure dynamic visibility changes in JavaScript are accompanied by corresponding ARIA state updates.
