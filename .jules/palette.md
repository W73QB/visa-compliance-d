## 2026-03-06 - [Accessibility] Google Material Symbols & Dynamic Select Labels
**Learning:** Google Material Symbols use ligatures (e.g., text like "verified_user") which act as visual icons but aren't explicitly hidden from screen readers. This causes screen readers to read the icon text verbatim if not hidden. Additionally, the complex layout separating dynamic form selects and their labels/hints breaks programmatic association without explicit ARIA linkage.
**Action:** Always add `aria-hidden="true"` to `<span class="material-symbols-outlined">` elements unless they are the sole interactive element requiring screen reader announcement. Also, explicitly link `<select>` elements using both the `for` attribute on the corresponding `<label>` and the `aria-describedby` attribute to link hint text for complete programmatic context.
